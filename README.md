# 🍽️ Canteen Website Front-End Prototype

A static web layout built using only **HTML** and **CSS**, designed as a mock front-end for a school canteen stall specializing in western food.  
This project was built as part of a school assignment to practice web development fundamentals. It is a **non-functional front-end prototype** with a focus on layout, styling, and content organization.

---

## 📋 Project Guidelines (Provided by Lecturer)

- The website had to be developed from scratch  
- At least 5 pages with a consistent look and feel across all pages  
- Layout must be fixed at **1024px width**  
- **JavaScript was not allowed**

---

## 📄 Pages Included

- **Home** (`index.html`) – Home page with promotions, signature dishes and membership benefits  
- **Food Menu** (`Food_Menu.html`) – Menu items with prices and images  
- **Order Page** (`order.html`) – Simulated order interface (UI only)  
- **About Us** (`About_us.html`) – Information about the stall (philosophy, address, contact number, etc) 
- **Member Page** (`Member.html`) – Basic UI for member registration 

---

## 🖼 Features

- Fully static layout — no JavaScript  
- Consistent navigation bar and layout across all pages  
- Visual menu with food images and category sections  
- Dedicated CSS files for each page to maintain clear styling separation  

---

## 🧰 Technologies Used

- HTML5  
- CSS3  
- Google Fonts  
- Local assets (images)

---

## 🧪 How to View the Site

1. Clone the repo: git clone https://github.com/LimJinBin32/canteen-website.git
2. Open `html/index.html` in your browser
